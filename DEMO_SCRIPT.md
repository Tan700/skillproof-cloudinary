# SkillProof — 3-minute demo script

## Hook — 0:00 to 0:25

"A resume can say someone knows IoT, React, or machine learning. SkillProof shows the work behind the claim through project media."

## Create — 0:25 to 0:50

Open `/dashboard` and create:

- Project: Smart Irrigation System
- Skills: IoT, ESP32, Sensors, C++
- Description: Automated irrigation using soil moisture sensing.

## Cloudinary upload — 0:50 to 1:25

Upload a 20–40 second video and one screenshot.

Point out:

- Cloudinary Upload Widget
- project folder
- `skillproof` and evidence tags
- contextual project ID metadata

## Transform + deliver — 1:25 to 2:05

Open the proof page.

Show that the video/image source URL uses transformations such as:

- video: `f_auto:video`, `q_auto`, width constraint
- image: `f_auto`, `q_auto`, width constraint

Explain that the app stores the Cloudinary public ID and delivery information rather than putting the original binary into the application database.

## Discover — 2:05 to 2:30

Open `/discover` and search `IoT`.

## Startup close — 2:30 to 3:00

"SkillProof starts as a proof-of-work portfolio for students. The scalable version becomes a recruiter discovery layer, a college project showcase, and eventually a media-backed talent graph. Cloudinary is the media infrastructure that makes that experience possible."
